# Project status

**Development source preview — not production-certified or broadly released.**

- **Aurora (Engine):** protected runtime and operational security implementation are not published here. Independent production security qualification remains outstanding.
- **Genesis (Model):** reference implementations and research experiments exist; no general-intelligence or production-quality model performance is implied.
- **Kyro (Interface):** a public information website and invite-only workspace are in development. Availability of source code does not establish end-to-end browser acceptance or production security.

**Public release decision: HOLD**, pending verified model quality, account and data-isolation tests, privacy and operations readiness, and independent Engine assessment.

Operational status, internal cloud resources, assessment results and deployment runbooks are maintained outside the public repository.

See [Systems Guide](../architecture/SYSTEMS_PUBLIC_GUIDE.md) and [Security Policy](../../SECURITY.md).
