**Date:** 2026-11-07 NZDT  
**Public code version:** v0.1  
**Maturity:** **pre-alpha reference software**, **not production-ready or general-public beta qualified**  
**Public source:** https://github.com/Hakaiki808-NZ/aurora-genesis  
**GitHub audit:** [7 November repository consolidation](../releases/GITHUB_REPO_AUDIT_2026_11_07.md)  
**Capability standard:** [Genesis Common AI Baseline 1.0](../standards/GENESIS_COMMON_AI_BASELINE_V1.md)

## Current components

- **Aurora / Engine** — execution authority and protected operational boundaries. Reference hardening suites exist; cloud Controller/Angel/Motor is a **restricted C1-only private alpha**. Privileged production Engine qualification is NOT established.
- **Genesis / Model** — deterministic research cognition, symbolic fact inference, memory/retrieval/provenance, policy/Guardian references, tool intent proofs, data-only knowledge modules, protected Genesis Core and starter university add-ons. Experimental Bedrock text gateway source is versioned but **disabled**; a third-party pretrained model's results are not Genesis-owned trained intelligence.
- **Kyro / Interface** — public website preview and private-alpha workspace infrastructure, Cognito-backed APIs and collaboration reference. Browser PKCE, full chat/storage/account isolation, accessibility, privacy and restore acceptance remain open.

## Model evidence and limits

- A tiny AWS neural training experiment saved **1,123 parameters** and validated checkpointing. It is not a useful conversational foundation model.
- No qualified live general-neural-model benchmark has been recorded against GCAB-1.
- Opt-in local/general model and hierarchical memory branches remain drafts until independent checks.
- No demonstrated AGI, consciousness, self-training of a competitive model or accredited university expertise.

## Blocking gates to public beta

1. **Model-quality proof** — issue [#44](https://github.com/Hakaiki808-NZ/aurora-genesis/issues/44).
2. **Real browser login, chat, persistence and isolation** — issue [#30](https://github.com/Hakaiki808-NZ/aurora-genesis/issues/30).
3. **Legal/privacy and operations** — reviewed retention/deletion, threat model, alerts with recipients, backup/restore and enforceable cost stop.
4. **Security and execution** — independent engine qualification before any Aurora privileged cloud operations.
5. **Formal go/no-go** — evidence tracked in [public beta gate](../releases/PUBLIC_BETA_GATE_2026_11_07.md).

**Release decision: HOLD.** Passing reference CI means code checks passed; it does not clear benchmark, security or browser-use acceptance.
