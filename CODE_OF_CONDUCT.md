# Code of Conduct

We want technical disagreement to be rigorous, respectful and useful.

Participants must:
- discuss ideas and evidence rather than attack people;
- avoid harassment, threats, discrimination and personal abuse;
- disclose conflicts of interest when materially relevant;
- respect privacy and security boundaries;
- report security vulnerabilities privately rather than publishing exploit details.

Maintainers may moderate participation that repeatedly disrupts safe, constructive collaboration.
