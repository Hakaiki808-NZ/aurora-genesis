# Public / Private Boundary

## Public

- Genesis reference implementation
- public Engine/Model contracts
- architecture descriptions
- tests and conformance material
- research and evaluation material
- examples
- RFCs and contributor documentation

## Private

- security-critical AURORA runtime implementation
- private signing keys and credentials
- protected recovery internals
- containment internals
- security-sensitive attestation/interlock implementation details where disclosure would weaken the boundary
- deployment secrets and machine-specific configuration

This boundary is part of the project architecture, not merely a repository-layout preference.
